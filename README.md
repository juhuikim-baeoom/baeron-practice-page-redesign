# 실습 안내 페이지 개편

배론 실습 안내 페이지의 수강신청 영역 개편안입니다. [사회복지현장실습](https://www.baeron.com/corp/new/practice_socialwork.asp)을 먼저 설계하고, [보육실습](https://www.baeron.com/corp/new/practice_child.asp)·[한국어교육실습](https://www.baeron.com/corp/new/practice_korean.asp)이 같은 구조에 얹히는지 확인하고 있습니다.

목업은 현행 페이지 구성(히어로 → 수강신청 안내 → 개설반 → 유의사항)을 그대로 따르며, 개편 대상은 가운데 개설반 영역입니다.

히어로는 현행이 통째로 이미지(대체텍스트 `하단 참조`)라 구법 120시간 / 신법 160시간 같은 핵심 안내가 낭독도 검색도 되지 않습니다. 배치와 문구는 그대로 두고 마크업만 글자로 옮겼습니다.

## 문제

개설반은 10개인데, 이를 보여주기 위해 표 8개(개강반별 일정표 4 + 신청표 4)를 세로로 쌓고 있어 스크롤이 지나치게 깁니다. 개설반이 1개뿐인 개강반도 제목·일정표·신청표 한 세트를 온전히 차지합니다.

## 개편안

**2단 탭 + 표 1개**로 접었습니다. 1단은 실습기관 소재지(수도권 / 전국권), 2단은 개강일입니다.

같은 값을 반복하지 않는 것이 원칙입니다.

| 값 | 어디에 한 번만 쓰는가 |
|----|----------------------|
| 학기 | 공통 정보 줄 (개강일이 학기 경계를 넘을 수 있으므로 개강일에 종속된 값으로 다룹니다) |
| 실습기관 소재지 범위 | 1단 탭 (탭 이름 아래 부연) |
| 수강료 | 공통 정보 줄 (지역이 정해지면 확정) |
| 개강일 | 2단 탭 |
| 수강기간 · 실습가능기간 | 2단 탭 아래 공통 정보 줄 (같은 개강일이면 항상 같은 값) |
| 세미나 요일·시간, 세미나 3회 날짜, 마감 여부 | 각 행 (반마다 다른 값) |
| ※ 안내 3줄 | 표 아래 한 번 (현행은 개강반 표 4개마다 반복) |
| 개강반 공지 | 개설반 안내 머리 한 곳 - 데이터 `notice_txt` 로 켜고 끕니다 (현행은 네 곳을 주석으로 켜고 끔) |

그 결과 표 컬럼이 7개에서 5개로 줄고, 화면에는 한 번에 한 지역·한 개강일만 보이므로 표가 항상 4행 이하가 됩니다. 모바일 카드 앞면은 1줄입니다.

2단의 기본 선택은 그 지역의 **가장 빠른 개강일**입니다. 1단·2단 탭 모두 줄 폭을 균등하게 나눠 갖고, 2단에는 반 개수를 쓰지 않습니다. 반 개수는 바로 아래 표의 행 수로 보이기 때문입니다.

1단 탭에는 지역 이름 아래 소재지 범위를 함께 적습니다. "수도권 / 서울, 경기, 인천 소재", "전국권 / 전국(섬 및 산간지역 제외) 소재" - 탭을 고르기 전에 판단 근거가 보여야 하므로 공통 정보 줄이 아니라 탭 안에 둡니다. 대신 수강신청 안내 표의 실습기관 행에서는 같은 정의를 빼고 탭을 가리킵니다.

함께 반영한 항목입니다.

- 비로그인 신청 경로 - 안내만 하고 끝나던 흐름을 로그인 후 복귀로 바꿉니다.
- 학기 교체 시 편집 지점을 데이터 배열 한 곳으로 모읍니다.

## 목업 실행

```bash
python3 -m http.server 8899
```

브라우저에서 `http://localhost:8899/mockup/practice-socialwork.html` 로 접속합니다.

창 너비를 768px 이하로 줄이면 모바일 배치(1줄 카드 + 일정 펼치기)로 바뀝니다.

색과 글꼴은 새로 만들지 않고 **현행 페이지에서 측정한 값을 그대로** 씁니다 - 흰 배경, 녹색 `#0d855d`, 표 머리 띠 `#d5f2e9`, 신청 버튼 주황 `#d94100`, 셀선 `#e1e1e1`, 글꼴 **Pretendard**. 개설반 영역만 색이 달라지면 같은 페이지 안에서 이질적으로 보이기 때문입니다. 자세한 대응표는 설계문서 §4.5 에 있습니다.

목업 상단에는 개편 내용을 적은 설명 패널이 있습니다. 기본은 접힌 상태이고 `설명 펼치기`로 볼 수 있습니다. 확인용 스위치는 접어도 남습니다. 둘 다 실제 페이지에는 없는 요소입니다.

| 스위치 | 하는 일 |
|--------|---------|
| 로그인 상태로 보기 | 신청 버튼이 로그인 경로 대신 수강신청으로 가는 상태 |
| 개설반 0건 상태 보기 | 선택한 지역에 개설반이 없을 때의 안내 화면 |
| 어두운 화면으로 보기 | 다크 모드 토큰 확인 |
| 과정 3개 | 개설반 영역을 사회복지 / 보육 / 한국어교육으로 바꿔 봅니다. 그 과정의 색 세트도 함께 적용됩니다 |
| 색 세트 5개 | 페이지 색을 한 벌씩 통째로 바꿔 봅니다 |

과정 스위치는 **개설반 영역만** 바꿉니다. 히어로·수강신청 안내·유의사항은 사복 것을 그대로 두었습니다 - 이번 개편 대상이 개설반 영역이고, 사복 화면이 확정되기 전에 나머지까지 세 벌로 늘리면 이후 수정이 세 배가 되기 때문입니다. 사복이 아닌 과정을 보는 동안에는 표 위에 그 사실을 밝히는 줄이 나옵니다.

| 과정 | 1단 축 | 표 컬럼 | 개설반 |
|------|--------|---------|--------|
| 사회복지현장실습 | 수도권 / 전국권 | 5 + 신청 | 10건 |
| 보육실습 | 없음 (탭 줄이 사라집니다) | 3 + 신청 | 3건 |
| 한국어교육실습 | 없음 | 4 + 신청 | 11건 |

색 세트는 앞의 셋이 현행 세 실습 페이지에서 측정한 값이고, 뒤의 둘은 제안입니다.

| 세트 | 강조 | 히어로 띠 | 성격 |
|------|------|-----------|------|
| 사회복지 | `#0d855d` 녹색 | `#188a6e` | 현행 |
| 보육 | `#554d72` 보라 | `#d44d51` 코랄 | 현행 |
| 한국어교육 | `#1f6699` 파랑 | `#3535b2` 남색 | 현행 |
| 중립 | `#333f45` 차콜 | `#2b3a41` | 색을 신청 버튼 하나로 모으는 안 |
| 딥그린 | `#125c43` 진녹 | `#0f5140` | 현행 녹색을 차분하게 낮춘 안 |

**신청 버튼 주황 `#d94100` 은 세 페이지가 모두 같이 쓰므로 세트마다 바뀌지 않습니다.** 히어로의 제목 알약·질문 버튼·맺음 문구는 띠 색에서 자동으로 만들어지고, 띠가 어두우면 맺음 문구를 밝게 뒤집습니다. 자세한 규칙은 설계문서 §4.5 에 있습니다.

## 배포

**https://baeron-practice-page-redesign.vercel.app/**

`main` 브랜치에 푸시하면 Vercel 이 자동으로 재배포합니다. 루트 `vercel.json` 이 루트 주소를 `mockup/practice-socialwork.html` 로 연결하고, `X-Robots-Tag: noindex` 로 검색엔진 색인을 막습니다. 검토용 목업이 실제 안내 페이지로 오인되는 것을 피하기 위해서입니다.

빌드 설정은 없습니다(정적 사이트). Vercel 프로젝트 설정에서 Application Preset 은 `Other`, Root Directory 는 `./` 입니다.

## 상태

설계문서와 목업이 확정된 상태입니다. 데스크톱(수도권·전국권)과 모바일 390px(접힘·펼침)에서 실제 렌더를 확인했습니다.

보육실습(`practice_child.asp`)과 한국어교육실습(`practice_korean.asp`)에도 같은 문제가 있습니다. **개설반 영역은 이미 세 과정이 한 구조를 쓰도록 데이터로 빼두었고**, 목업 상단 과정 스위치로 확인할 수 있습니다. 히어로·수강신청 안내·유의사항은 사복 확정 후에 같은 방식으로 뺍니다. 목업을 복사해 세 벌로 늘리지는 않습니다. 측정값과 과정별 차이는 설계문서 §7.1에 있습니다.

넘겨야 할 것이 하나 남았습니다.
