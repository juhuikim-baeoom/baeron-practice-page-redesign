# 사회복지현장실습 안내 페이지 개편

배론 [사회복지현장실습 안내 페이지](https://www.baeron.com/corp/new/practice_socialwork.asp)의 개설반 영역 개편안입니다.

## 문제

개설반은 10개인데, 이를 보여주기 위해 표 8개(개강반별 일정표 4 + 신청표 4)를 세로로 쌓고 있어 스크롤이 지나치게 깁니다. 개설반이 1개뿐인 개강반도 제목·일정표·신청표 한 세트를 온전히 차지합니다.

## 개편안

실습기관 소재지(수도권 / 전국권) 기준 **탭 2개 + 통합표 1개**로 접습니다. 지역이 정해지면 수강료가 확정되므로(수도권 300,000원 / 전국권 400,000원) 수강료는 탭 헤더 아래 안내줄로 올렸습니다.

함께 반영한 항목입니다.

- 잔여석 표시 — 데이터는 이미 있었으나 화면에 노출되지 않았습니다.
- 비로그인 신청 경로 — 안내만 하고 끝나던 흐름을 로그인 후 복귀로 바꿉니다.
- 학기 교체 시 편집 지점을 데이터 배열 한 곳으로 모읍니다.

## 구성

| 경로 | 내용 |
|------|------|
| `docs/superpowers/specs/2026-08-20-사회복지현장실습-페이지-개편-design.md` | 설계문서 — 현황 진단, 탭 기준 선정 근거, 기각한 대안, 컬럼 구성, 상태 처리, 데이터 구조, 미해결 이슈, 후속 과제 |
| `data/classes-2026-2.json` | 2026학년도 2학기 개설반 10건 |
| `mockup/practice-socialwork.html` | 동작하는 목업 (단일 파일, 의존성 없음) |

## 목업 실행

```bash
python3 -m http.server 8899
```

브라우저에서 `http://localhost:8899/mockup/practice-socialwork.html` 로 접속합니다.

목업 하단의 확인용 스위치로 로그인 상태, 개설반 0건 상태, 마감임박 강조를 각각 확인할 수 있습니다. 실제 페이지에는 없는 요소입니다.

## 상태

설계문서 검토 단계입니다. 미해결 이슈 한 건(9월 4일 개강반의 구별 불가능한 중복 개설반)은 운영 부서 확인이 필요하며, 설계문서 §6.1에 정리했습니다.
